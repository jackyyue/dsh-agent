# DSH Agent 设置指南

## 下载

访问 [dsh-agent.com](https://dsh-agent.com)，点击"下载 DSH Agent"按钮。

文件大小约 200MB，适用于 Windows 10/11 (64位)。

## 安装

1. **双击下载的文件**

   找到下载的 `dsh-agent.exe`（通常在"下载"文件夹），双击运行。

2. **获取 DeepSeek API Key**

   软件启动后，会提示你需要一个 DeepSeek API Key。

   **还没有 Key？**
   - 点击"点这里，我帮你打开注册页面"按钮
   - 在打开的页面注册账号（手机或邮箱）
   - 进入"API Keys"页面
   - 点"创建新密钥"
   - 复制 `sk-` 开头的那串字符

   **已经有 Key？**
   - 直接粘贴到输入框

3. **开始安装**

   粘贴 Key 后点击"开始"按钮。

   软件会自动：
   - 验证 Key 是否有效
   - 检测你的系统环境
   - 下载必要的文件
   - 配置 DSH
   - 启动服务
   - 自动测试

   整个过程约 2 分钟，跟着提示走就行。

4. **完成**

   安装完成后，桌面会出现"DSH"图标。

   双击即可开始使用。

## 常见问题

**Q: DeepSeek API Key 是什么？**

A: 一个授权码，让 DSH Agent 能调用 DeepSeek 的 AI 能力。注册是免费的，每天有免费额度。

**Q: Key 会被上传吗？**

A: 不会。Key 保存在你的电脑上，只用于本地调用 DeepSeek API。

**Q: 提示"Key 无效"怎么办？**

A: 检查：
1. 是否复制完整（应该是 `sk-` 开头的长字符串）
2. 是否在 DeepSeek 控制台确认 Key 处于"启用"状态
3. 网络是否正常

**Q: 安装过程中断了怎么办？**

A: 关闭软件，重新双击运行即可。已完成的部分不会重复。

**Q: 遇到其他问题？**

A: 双击桌面"装机助手"图标，它会自动诊断并帮你修复。
