DSH Agent

开箱即用的 AI 助手，双击即可对话

安装只需 3 步，全程点一点、粘一粘，大约 2 分钟：

  1. 准备一个免费的 DeepSeek API key（1 分钟）
  2. 下载安装包并双击运行
  3. 按软件里的指引完成设置，开始对话

第一步：准备 DeepSeek API key

点击下方按钮，打开 DeepSeek 官网注册账号并创建 API key。它是免费的，拿来配好软件就能用了。

打开 DeepSeek → 创建 API key

注册后在右上角点「创建 API key」，复制以 sk- 开头的那串字符。稍后安装时会用到。

第二步：下载安装包

点击下方按钮下载（约 44 MB）。

下载完成后双击运行即可，软件会自动完成安装设置。

如果没有自动开始下载，点这里手动下载。
